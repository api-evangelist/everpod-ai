Everpod provides always‑on cloud computers for AI agents, enabling Claude Code, Codex, OpenClaw and others to run on a persistent, secure, backed‑up machine. Users can launch developer pods, manage keys, and integrate via the MCP server, with pricing plans and robust security. This platform empowers developers to give AI agents permanent compute resources.

**Areas:** AI · Cloud Computing · Developer Tools · Platform · Agents

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Everpod: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
